# 餐飲單店創業前財務風險評估

輸入一份餐飲創業計畫，系統以現金基礎（不攤提啟動資金）計算月損益、損益兩平營業額、安全邊際、SPLH 區間與含養店期的回本月數，並與經濟部餐飲業產業數據比較，依判斷表給出結論：不可行／不建議／可行，但獲利偏低／可行。

## 本地執行

```bash
pip install -r requirements.txt
streamlit run app.py
```

瀏覽器會開啟 http://localhost:8501 。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `engine.py` | 計算引擎與判斷規則（不含畫面），產業基準值、法規參數、範例資料都在這裡 |
| `app.py` | Streamlit 畫面 |
| `requirements.txt` | 套件清單 |

## 部署到 Streamlit Community Cloud

1. 把三個檔案推到 GitHub 儲存庫。
2. 在 share.streamlit.io 選擇該儲存庫，主檔案填 `app.py`。

## 待查證的假設值

- 兼職法定負擔倍數 1.11
- 資金機會成本年利率 1.7%
- 安全邊際提示門檻 20%（只用於風險說明，不影響結論）
- 養店期第 1–6 個月營業額比例 60、60、70、70、80、80%（依作者經營經驗校準）
